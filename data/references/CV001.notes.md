## Annotation choices

- Use visible PDF content, including placeholder names and dates. No candidate facts were looked up externally or inferred from the sample's author. Icons identify platforms but are not copied as text.
- Normalize layout line wraps and ligatures, rejoining words split only by wrapping. Retain source spelling, including non-existant, AmaZing and the accented address. Publication source_text uses the same whitespace and ligature convention.
- The headline is not assumed to be an occupation. Given/family names, native language, degree completion and other unstated facts remain null.
- Links retain their visible website, handle or identifier in url; platform records distinguish the three your_id handles. Do not substitute embedded hyperlink destinations: rendered-image methods cannot see them. Do not invent protocols or expanded profile URLs.
- Each job has one position containing its dates, location and bullets. Ongoing explicitly sets is_current=true. Month 20XX remains a placeholder. No employment/project relationships are invented.
- Each project's displayed funding organization is in organization. Details is a description; Project duration is a literal duration placeholder. The schema does not identify whether the organization is a funder, employer or owner.
- Strength tags are separate skills, without invented soft/technical categories or levels.
- Language ratings are visually English=5, Spanish=4 and German=3.5, maximum=5. German has a half-filled circle. No CEFR mapping, native status or explicit lower bound is invented. raw_value and scale_description describe graphical marks rather than printed text.
- The philosophy is profiles[type=other]. MOST PROUD OF stays in additional_sections because achievements are not necessarily awards. The repeated achievement is retained twice.
- A DAY OF MY LIFE is a chart description plus five labels. No numeric values or units are printed, so no proportions are estimated. The header's decorative globe is excluded from semantic evaluation.
- The book's Somewhere, Some Place and conference citation's Far Far Away stay in local additional sections: exact bibliographic roles are not established. Author initials and publication source order are preserved.
- Referee titles are separate from names. Address lines stay in local additional sections because the PDF does not establish whether they are personal or institutional addresses.

## Evaluation boundary

Validate outputs with RawCV before comparison so omitted defaults and explicit defaults agree. Optional entry IDs, source excerpts, page metadata, generated graphical descriptions and arbitrary labels such as Publication details need separate rules; exact wording of those annotations should not count as candidate-data accuracy. Do not use whole-JSON string equality as the accuracy metric. This file defines expected content; it does not implement an evaluator.
