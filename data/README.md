# Data

Stores CVs, sources and manually checked reference data.

`manifest.json` lists each PDF by ID, path (relative to this directory), original source URL, and a key into the shared `sources` section. That section records attribution and the published license or permission. Pinned source links identify the collected version where available.

PDF contents are unchanged; only local filenames may differ. Original license notices are preserved in `licenses/`. The repository's MIT license applies to original project code, not these third-party CVs.

VDAB examples are recorded for internal informational/educational evaluation. Their terms have not been established as permission to redistribute a public test dataset. A manifest documents provenance; it does not grant additional rights.
